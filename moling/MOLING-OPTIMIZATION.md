# 魔灵算码

通用流程见 `HOWTO-OPTIMIZATION.md`。本文只写魔灵自己的文件、目标和当前起步布局。命令都在 `moling/` 目录下执行。`SCHEMA=moling`。

## 1. 文件

| 用途 | 文件 |
|---|---|
| 配置 | `config.toml` |
| 键位分布 | `key_distribution.txt` |
| 输出目录 | `moling-output/output-<时间戳>/` |
| 宇浩方案 | `../../yuhao-assess-data/schemes/moling.json` |

`key_distribution.txt` 是魔灵和未单独配置键位文件的方案用的。

优化循环里只改 `config.toml` 和 `key_distribution.txt`。其它输入不动。

`pair_equivalence.txt` 现为宇浩测评使用的陈氏当量，与速度当量同一标准和刻度。参考布局 `output-20260603-072215` T3 的内部当量 0.1323 对应北语速度当量 1.2577。语料和简码仍可能让两个平均数差一截，五项指标仍以宇浩数字为准。

魔灵固定单键简码是 `不 u`、`是 i`、`我 o`、`的 e`、`了 a`。简码优化关闭。

设计背景在 `~/home/yu/src/zht/ime/moling.md`。那是方案说明，不是本轮优化规格。魔灵是 25 键方案，不用 `z`。声母按灵明的方式归并：`z/zh` 并到 `v`，零声母用 `w`，`y` 并到 `k`，减轻 `Y` 键。字根按形归类，摆法参照灵明。非成字字根和不常用字根不取声码，韵码取首笔，映射到 `A` 折、`E` 撇、`U` 竖、`I` 点、`O` 横。已发布版本对三码字根的韵码还有一次左右手次映射（右手 `U/I/O` 改到 `E`，左手 `E` 改到 `I`、`A` 改到 `U`）。单字全码是 `A1A2A3AzSzYz`，双根字是 `A1A2S2S1Y1`，最长四码。不跳过第三根，常用字根可以组两字词。

笔画次映射已经加回。三码字根的补码仍按首笔，再按声母左右手做一次替换：左声母加撇、左声母加折、右声母加横竖点，映射见 `prepare-inputs.sh` 里的 `stroke_mapping`。零声母、y、z 和五个笔画不参与退火，固定为 w、k、v 和 o/u/e/i/a。「土」的声码固定为 D（`USE_PINYIN_DU_FOR_TU=1`，读音 dù）。「口」的声码固定为 k，不再交给退火。不设置 `OPTIMIZE_KEYS`，只退火字根首码。准备输入和优化都不要带 `OPTIMIZE_KEYS`：

```bash
./prepare-inputs.sh
./optimize.sh --seed-keymap moling-output/output-20261012-094112/thread-00/output-keymap.txt
```

`optimize.sh` 默认会再执行 `prepare-inputs.sh`，所以退火命令也要带同一个变量。改过 `prepare-inputs.sh` 之后的第一次优化不要设 `NO_PREPARE=1`。

当前起点是 `moling-output/output-20261012-094112/thread-00/output-keymap.txt`。那份种子里「土」的声码是 T，当前输入把「土」固定成 D，这一位不跟着种子。

## 2. 全码目标

| 指标 | 目标 |
|---|---|
| 通用规范，全码静态重码字数 | 不多于 800 |
| 知乎简体，频率降序全码动态重码率 | 不多于万分之 2 |
| 北语简体，频率降序全码动态重码率 | 不多于万分之 2.5 |
| 知乎简体，全码速度当量 | 不高于 1.245 |
| 北语简体，全码速度当量 | 不高于 1.250 |

五项里，实际值等于目标也算达标。优先级用 `HOWTO-OPTIMIZATION.md` 的默认。按键热力在 HOWTO 的默认倒 T 之外，魔灵另行指定：A 不多于 4%，Q、P、Y、C 各不多于 3%，B 不多于 2%。

当量按上面的北语比例对齐。`scale.equivalence` 为 `0.30 × 1.2577 / 0.1323 = 2.85204`。`targets.full_code.equivalence` 取较紧的知乎上限 1.245。旧目标 0.125 乘同一比例是 1.188，比这次的速度上限更紧。权重没有乘这个比例。当量变异系数没有单位，不缩放。增量优化用 `_max` 把内部指标圈在起点附近，起点本身要能通过。
